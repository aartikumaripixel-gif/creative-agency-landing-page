# Creative Digital Agency Landing Page

A creative digital agency landing page inspired by modern agency websites. Built using HTML, CSS and JavaScript, with GSAP-powered scroll-triggered image animations and a visually engaging layout.

## Features
- Creative hero section with outlined typography and hover effects
- Navigation bar with logo and menu links
- Introductory text section
- Featured projects section with text and image layout
- Scroll-triggered image reveal animations
- GSAP animations with blur, fade, movement and scaling effects
- Development section
- Image-based cards and content slides
- Clean typography and modern styling

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- Remix Icon

## Concepts Practiced
- Flexbox layouts
- CSS positioning
- DOM manipulation
- GSAP timelines
- ScrollTrigger
- CSS hover effects
- Image styling and layering
- JavaScript event handling
